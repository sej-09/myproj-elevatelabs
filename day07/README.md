# 🌐 Task 7 - Fetch and Display Data from Public API

## 📌 Objective
In this task, I used JavaScript Fetch API to retrieve user data from a public API and display it on a webpage.

## 🔗 API Used
https://jsonplaceholder.typicode.com/users

## 🛠 Technologies Used
- HTML
- CSS (Modern Glassmorphism UI)
- JavaScript
- Fetch API
- Async/Await
- Git & GitHub

## 🚀 Features
- Fetches real-time user data from API
- Displays:
  - Name
  - Email
  - Address
- Reload button to refetch data
- Error handling using try-catch
- Responsive and modern UI design
- Network error testing supported

## 🧠 Concepts Learned
- Fetch API
- Promises
- Async JavaScript
- JSON parsing
- HTTP status handling
- Error handling

## 📂 Project Structure
task07-fetch-api/
│── index.html

## 📷 Output
Users are displayed in responsive cards with modern styling.

## 🎯 Outcome
This task helped me understand how asynchronous JavaScript works and how APIs are integrated into web applications.
